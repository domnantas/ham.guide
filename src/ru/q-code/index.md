# Международный Q-код

| Сокращение | Вопрос                                      | Ответ                                                                                                              |
| ---------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **QRG**    | Какая точная частота?                       | Точная частота — ...                                                                                               |
| **QRK**    | Какова разборчивость моего сигнала?         | Разборчивость сигнала: 1. Плохая; 2. Довольно плохая; 3. Удовлетворительная; 4. Хорошая; 5. Отличная.               |
| **QRL**    | Вы заняты? Частота используется?            | Я занят. Частота используется.                                                                                     |
| **QRM**    | Вам мешают другие станции?                  | Мне мешают другие станции. 1. Совсем не мешают; 2. Незначительно; 3. Умеренно; 4. Сильно; 5. Очень сильно.          |
| **QRN**    | Вам мешают атмосферные помехи?              | Мне мешают атмосферные помехи. 1. Совсем не мешают; 2. Незначительно; 3. Умеренно; 4. Сильно; 5. Очень сильно.      |
| **QRO**    | Увеличить мощность передатчика?             | Увеличьте мощность передатчика.                                                                                    |
| **QRP**    | Уменьшить мощность передатчика?             | Уменьшите мощность передатчика.                                                                                    |
| **QRS**    | Передавать медленнее?                       | Передавайте медленнее.                                                                                             |
| **QRT**    | Прекратить передачу?                        | Прекратите передачу.                                                                                               |
| **QRU**    | У вас есть что-нибудь для меня?             | У меня для вас ничего нет.                                                                                          |
| **QRV**    | Вы готовы?                                   | Я готов.                                                                                                           |
| **QRX**    | Когда вы меня вызовете?                      | Я вызову вас в... (время). Или: Подождите.                                                                         |
| **QRZ**    | Кто меня вызывал?                           | Вас вызывает...                                                                                                    |
| **QSA**    | Какова сила моего сигнала?                  | Сила сигнала: 1. Плохая; 2. Довольно плохая; 3. Удовлетворительная; 4. Хорошая; 5. Отличная.                        |
| **QSB**    | Мой сигнал замирает (фединг)?               | Ваш сигнал замирает.                                                                                               |
| **QSL**    | Вы подтверждаете приём?                     | Подтверждаю приём.                                                                                                 |
| **QSO**    | Можете связаться со... (мной)?             | Я могу связаться с... (вами).                                                                                       |
| **QSX**    | Можете слушать на... (частоте)?            | Я слушаю на... (частоте).                                                                                           |
| **QSY**    | Сменить частоту передачи?                   | Смените частоту передачи на...                                                                                     |
| **QTC**    | У вас есть для меня сообщение?              | У меня есть для вас сообщение.                                                                                      |
| **QTH**    | Где вы находитесь?                          | Я нахожусь в... (указывается населённый пункт или координаты).                                                     |
| **QTR**    | Какое точное время?                         | Точное время — ...                                                                                                 |
