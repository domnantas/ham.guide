# Советы по Markdown

## Заголовки

```md
# заголовок h1

## заголовок h2

### заголовок h3

#### заголовок h4

##### заголовок h5

###### заголовок h6
```

#### Пример

# заголовок h1

## заголовок h2

### заголовок h3

#### заголовок h4

##### заголовок h5

###### заголовок h6


#### Пример

---

## Выделение

```md

```

#### Пример

## Списки

### Ненумерованные

```md
- Списки
  - могут быть
    - нескольких уровней
  - второй уровень
```

#### Пример

- Списки
  - могут быть
    - нескольких уровней
  - второй уровень

### Нумерованные

```md
1.  Неважно, с какого
1.  числа начинается
1.  строка списка
```

#### Пример

1.  Неважно, с какого
1.  числа начинается
1.  строка списка

## Контейнеры сообщений

```md
::: tip СОВЕТ
Это подсказка
:::

::: warning ВНИМАНИЕ
Это предупреждение
:::

::: danger ОПАСНОСТЬ
Это предупреждение об опасности
:::
```

#### Пример

::: tip СОВЕТ
Это подсказка
:::

::: warning ВНИМАНИЕ
Это предупреждение
:::

::: danger ОПАСНОСТЬ
Это предупреждение об опасности
:::

Можно изменить заголовок сообщения:

```md
::: danger STOP
Опасно, дальше не идите
:::
```

#### Пример

::: danger STOP
Опасно, дальше не идите
:::

## Код

### Внутри текста

```md
Код `в той же` строке
```

#### Пример

Код `в той же` строке

### В отдельном блоке

````md
```js
var foo = function (bar) {
  return bar++;
};
```
````

#### Пример

```js
var foo = function (bar) {
  return bar++;
};
```

В блоках кода можно подсвечивать строки:

````md
```js{2,3}
const foo = bar => {
  bar++;
  console.log(bar);
};
```
````

#### Пример

```js{2,3}
const foo = bar => {
  bar++;
  console.log(bar);
};
```

## Vue-компоненты

В `markdown`-файлах этого проекта можно использовать компоненты [Vue](https://vuejs.org/)

