# Руководство

Помощь сообщества очень приветствуется! Не переживайте, если у вас мало опыта работы с проектами с открытым исходным кодом или с git — на этой странице приведены рекомендации для начинающих.

## Чем я могу помочь?

Прежде всего — спасибо, что хотите помочь этому проекту расти. Есть множество способов внести свой вклад — расскажите друзьям о ham.guide, исправьте найденные грамматические ошибки, уточните устаревшую информацию, переведите страницы на другой язык или даже добавьте новое содержание. На нашей [странице Github Issue](https://github.com/domnantas/ham.guide/issues) ищите сообщения, помеченные _help wanted_, и попробуйте помочь с их решением.

## _Issues_

Если у вас есть предложения, вопросы или вы нашли ошибки, напишите сообщение на нашей [странице Github Issue](https://github.com/domnantas/ham.guide/issues).

## Редактирование для начинающих

Если вы нашли грамматическую ошибку, неверную информацию или хотели бы что-то уточнить, выполните следующие шаги:

- Прокрутите до низа страницы, которую хотели бы отредактировать, и нажмите ссылку **Редактировать эту страницу**. Вы будете перенаправлены на Github, и для отправки изменений вам потребуется создать учётную запись, если её у вас ещё нет.
- После входа нажмите кнопку **Fork this repository and propose changes**.
- Внесите изменения на страницу и в разделе _Propose file change_ объясните, что и почему вы изменили.
- Нажмите кнопку **Propose file change**, а затем **Create pull request** на следующей странице.
- Убедитесь, что ваш _pull request_ имеет подходящий заголовок и описание, и нажмите **Create pull request**.

Спасибо, что улучшаете ham.guide! Мы рассмотрим ваши изменения, и обновлённую страницу вы увидите после того, как мы подтвердим изменения. Время от времени проверяйте свой [_pull request_](https://github.com/domnantas/ham.guide/pulls) — там вы можете найти комментарии и вопросы, связанные с вашими изменениями.

## Редактирование для продвинутых

### Vuepress

Проект создан с использованием [Vuepress](https://vuepress.vuejs.org/).

### Запуск в локальной сети

#### Windows

В этом случае рекомендую использовать [WSL](https://medium.com/@johnwoodruff91/epic-dev-environment-with-wsl-dc81e234ae61) и таким образом установить Git и Node.

#### MacOS

Установите Git и Node по этим [инструкциям](https://gist.github.com/nerdenough/d288f2e732637f55f9858070c6b8b15b) (или следуйте похожему руководству, которое можно найти в интернете).

#### Linux

Используя менеджер пакетов вашего дистрибутива, установите программы Git и Node.

---

Также потребуется [установить Yarn](https://yarnpkg.com/getting-started/install)

---

1. Когда установите Git и Node, [клонируйте репозиторий ham.guide и создайте новую ветку](https://gist.github.com/Chaser324/ce0505fbed06b947d962).

1. Установите необходимые модули

```bash
yarn
```

3. Запустите локальный сервер

```bash
yarn dev
```

Откройте `localhost:8080`, и вы должны увидеть работающий локально ham.guide.

### Структура проекта

```
.
├── src
│   ├── .vuepress
│   ├── contribute
|   ├── phonetic-alphabet
|   ├── q-code
|   ├── radio-operating-ethics
│   └── ru
│       ├── contribute
│       ├── phonetic-alphabet
│       ├── q-code
│       └── radio-operating-ethics
├── CHANGELOG.md
├── LICENSE
├── package.json
└── README.md
```

Это упрощённая схема структуры проекта.

- В папке `src/` размещается всё содержание сайта.
- В `src/.vuepress` находятся файлы конфигурации и стилей Vuepress, каталоги компонентов и публичных файлов. Больше информации об этом можно найти в [документации Vuepress](https://vuepress.vuejs.org/), но этим файлам редко нужны изменения.

```{4,5,6,7}
.
├── src
│   ├── .vuepress
│   ├── contribute
│   ├── phonetic-alphabet
|   ├── q-code
|   ├── radio-operating-ethics
│   └── ru
│       ├── contribute
|       ├── phonetic-alphabet
|       ├── q-code
│       └── radio-operating-ethics
...
```

Папки `src/contribute/` или `src/q-code/` — это папки **страниц** или **групп страниц**. **Страница** — это папка, содержащая один файл `README.md`. **Группа страниц** — это папка, содержащая `README.md` и другие `.md`-файлы для дополнительных страниц.

::: warning Предупреждение
Если вы хотите создать **новую** страницу или группу страниц, потребуется изменить настройку `themeConfig.locales.sidebar` в файле `src/.vuepress/config.ts`, чтобы ваша страница отображалась в навигации. Попробуйте сделать это самостоятельно, используя уже написанный код как пример, но не бойтесь просить помощи на нашей странице Github, если застрянете!
:::

```{8,9,10,11,12}
.
├── src
│   ├── .vuepress
│   ├── contribute
│   ├── phonetic-alphabet
|   ├── q-code
|   ├── radio-operating-ethics
│   └── ru
│       ├── contribute
|       ├── phonetic-alphabet
|       ├── q-code
│       └── radio-operating-ethics
...
```

Папки, названные по двухбуквенному коду страны, — это **папки языков**. Язык по умолчанию в этом проекте — английский, поэтому папкам `src/contribute/` и `src/radio-operating-ethics/` папка языка не нужна. Другие языки обязательно должны иметь папку языка, и она _должна_ содержать те же **страницы** и **группы страниц**, что написаны на английском языке.
